# File-by-file review

Review date: 22 October 2026. Companion assessment: [PROJECT_REVIEW.md](PROJECT_REVIEW.md).

This inventory accounts for all **376 tracked project files** before these review documents were added. It distinguishes implementation review, test-scenario inspection, notebook inspection, and binary inventory. The parent PROJECT_STATUS_FOR_CLAUDE.md was also read and is obsolete in several important areas. Generated dependencies, git internals, caches, local databases, private calibration datasets, private weights and .env secrets are outside the maintained-source review. No claim is made that every screenshot or font was visually audited. Two screenshots were visually inspected; the others are individually listed as inventory. The notebook was not retrained.

The findings and proposed changes are recommendations; application files were not edited by this review. A file with no unique finding is not a claim that it has no bugs. Tests were inspected for scenarios and gaps; this is not exhaustive path coverage. Four late independent edits to Screen.tsx, Screen.module.css, SignIn.tsx and SignIn.module.css were also inspected: they add a narrow desktop sign-in layout and separate desktop submit buttons. Recheck responsive button visibility and sign-in tests for that new layout; earlier validation does not cover subsequent edits.
