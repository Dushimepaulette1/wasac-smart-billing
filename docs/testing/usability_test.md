# Usability test (System Usability Scale)

The proposal planned SUS scores. Run this with real people only; report only real answers and how many took part.

**Tasks** (watch, do not help; note if each was finished and any trouble):
1. Sign in with the number given.
2. Send a meter reading from a photo.
3. Find your bill and how much you owe.
4. Start paying the bill.
5. Find out why a reading was held.

**Questions** (1 strongly disagree to 5 strongly agree):
1. I think I would like to use this app often.
2. I found the app unnecessarily complex.
3. I thought the app was easy to use.
4. I think I would need help from a technical person to use it.
5. I found the parts of the app worked well together.
6. I thought there was too much inconsistency in the app.
7. I think most people would learn to use this app very quickly.
8. I found the app very awkward to use.
9. I felt very confident using the app.
10. I needed to learn a lot before I could use this app.

**Score:** odd questions: answer minus 1. Even questions: 5 minus answer. Add them and multiply by 2.5 (0 to 100).
Average across people. 68 is the commonly quoted average.
